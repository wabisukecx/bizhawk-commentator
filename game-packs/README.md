# Game packs

Place trusted game-pack `.zip` files directly in this folder, then restart the app/MCP service and BizHawk's Lua bridge. ZIP files here are local installation data and are ignored by Git.

To create or update `fe1-jp-v1.zip` here from the FE1 sources, run `npm.cmd run game-pack -- export-fe1` from the project root.

Pack format, building, updating and examples: [ゲームパックの作成と導入](../docs/game-packs.ja.md).

# BizHawk Commentator

BizHawkでプレイ中のゲームを観測し、Claudeによる短いコメントを字幕・音声で届けるローカルアプリです。MCPサーバーとして、Claudeとのチャットにゲーム画面や状態を渡すこともできます。

## 主な機能

- 日本語・英語の字幕と、ブラウザの音声合成による読み上げ。
- 4種類の口調と、発言頻度・Sonnet／Haikuの選択。
- 対応する初代『ファイアーエムブレム』日本版のRAMから、戦闘・回復・成長・敵の接近・仲間の加入などを実況。
- 観測後の敵の追加、村の破壊・宝箱の開封、回復地形上のHP増加、兵種変更も実況します。戦闘では特効・低命中率の補足、レベルアップ間近の経験値、味方フェーズでは残りの未行動人数を条件に応じて伝えます。
- 戦闘結果などはローカルの定型文で伝え、Claudeは直近の消耗や配置の流れを短く解説。結果の言い直しや称賛だけになる場合は発言を控えます。会話では台詞の情報やヒントを解説します。
- MCP経由でゲーム画面、接続状態、最近の観測差分を取得。
- ROM識別・RAM解析・実況ルール・名前表をZIPのゲームパックとして追加。

ゲーム操作はプレイヤーが行います。公開するブリッジには、コントローラー入力・RAM書き換え・セーブステート変更の機能はありません。

## 必要なもの

- WindowsとNode.js 22以上。
- [BizHawk](https://github.com/TASEmulators/BizHawk/releases)。動作確認対象は2.11.1です。
- 自分で用意したゲームROM。ROM・エミュレーター本体は同梱していません。
- 自動実況を使う場合：サブスクでログイン済みのClaude Codeと、音声合成に対応したブラウザ。
- MCPチャットを使う場合：ローカルMCPサーバーに対応したクライアント（Claude Desktopなど）。

自動実況はClaude Codeのサブスク認証を利用します。開始前にClaudeアカウントの追加使用量をオフにしたことを確認してください。このアプリからアカウント側の設定を変更することはできません。

## セットアップ

リポジトリをダウンロードまたはクローンし、プロジェクトのフォルダでPowerShellを開きます。

```powershell
npm.cmd ci
```

本体のビルドは不要です。FE1の解析パックは`game-packs/fe1-jp-v1.zip`として同梱しています。開発用ソースは配布しません。BizHawkは別途用意してください。以下のコマンドのエミュレーターとROMのパスは、使用するファイルの場所に置き換えます。

## 自動実況を使う

1. `start-commentator.cmd`をダブルクリックします。操作画面は`http://127.0.0.1:8989`で開きます。
2. 別のPowerShellから、次のコマンドでBizHawkを接続します。

   ```powershell
   .\scripts\start-bizhawk.ps1 -EmuHawk 'C:\Emulators\BizHawk\EmuHawk.exe' -Rom 'C:\Games\game.nes'
   ```

3. 操作画面で言語・口調・モデル・発言頻度を選び、利用設定の確認後に「見守りを開始」を押します。
4. 操作画面を開いたままプレイします。字幕・履歴が表示され、利用可能な音声で読み上げます。

PowerShellからアプリだけを起動する場合は`npm.cmd run app`を実行します。Claude Desktopを同時に起動する必要はありません。`http://127.0.0.1:8989/overlay`では字幕用の表示を開けます。

言語・口調・モデルを変える場合は、一度見守りを停止してください。操作画面を閉じると、約5秒後に見守りを停止します。

定型実況はClaudeの呼び出し回数に数えません。Claudeへの生成要求は、発言頻度に応じて1時間25／45／60回が上限です。生成に失敗した場合や上限に達した場合は見守りを停止します。これらはアプリ独自の制限で、サービス側の利用枠とは異なります。

## MCPチャットで使う

Claude Desktopの設定へ登録するには、次を実行します。

```powershell
node scripts/register-claude.js
```

既存設定を保持し、変更前にバックアップを作成します。登録後はClaude Desktopを完全に終了し、起動し直してください。

設定内容を表示して手動登録する場合は、次を実行します。出力にはインストール先に合わせたパスが入ります。

```powershell
node scripts/claude-config.js
```

クライアントがMCPサーバーを起動した後、「自動実況を使う」の手順と同じコマンドでBizHawkを起動します。チャットでは、例えば次のように依頼できます。

> get_session_infoで接続を確認してから、get_game_contextで現在の画面を取得し、状況を短く説明してください。

| ツール・プロンプト | 内容 |
|---|---|
| `get_session_info` | 接続状態、ROM情報、対応機能を取得 |
| `get_game_context` | 同じフレームのPNG画像とメタデータを取得。対応ROMではRAM情報も含む |
| `get_recent_events` | Luaが記録した最近の観測差分を最大128件取得 |
| `commentate` | 取得した場面について、日本語で短く話すためのプロンプト |

MCPチャットでは、ツールを呼んだ時点の静止画と状態を取得します。継続的な自動実況には、字幕アプリの見守り機能を使ってください。

## 対応範囲

ゲーム用の解析・実況処理は、ZIPパックを`game-packs/`へ置き、アプリ／MCPサービスとLuaを再起動して追加します。本体に内蔵ゲームはありません。FE1の解析・実況処理は同梱ZIPにまとめています。[ゲームパックの作成と導入](docs/game-packs.ja.md)を参照してください。

- 自動実況用のRAM解析は、初代『ファイアーエムブレム 暗黒竜と光の剣』日本版の特定ROMに対応します。対象のBizHawk ROM SHA-1は`8600D1880EB311BAE0ECE197F6175228E38F6B69`です。
- ROM名だけでは対応を判断しません。対象外のROMやマップ情報を読み取れない場面では、自動実況を行いません。MCPの画面取得は別に利用できます。
- 全章・全場面の動作は検証できていません。味方死亡・後半章は検証が残っています。
- 敵の追加・村・宝箱・兵種変更などの新しい実況は自動テストで検証していますが、実プレイでの表示タイミング・全場面の確認は残っています。回復地形上のHP増加は、回復の原因まで確定しません。未行動人数は、実際に行動可能な人数を保証しません。
- 自動実況では先の展開を予告しません。RAMの章番号は画面より先に変わる場合があるため、章番号の変化だけでは章開始を実況しません。MCPで先の展開を尋ねる場合は、質問の範囲で扱えますが、取得できる解析情報には限りがあります。
- 地形を考慮した移動経路・敵AIの意図・確実な撃破予測は扱いません。
- アイテムの入手・交換・破損の実況、プレイヤーの音声認識には対応していません。
- 字幕の表示時間は文字数から推定し、読み上げ終了とは同期していません。音声の種類・品質はブラウザとOSに依存します。
- 英語の人物名にはローマ字表記へのフォールバックがあります。同梱ZIP内の`english-names.md`を参照してください。

## データと接続

接続先はローカルホストです。BizHawkとのTCP接続には既定で`127.0.0.1:8766`、操作画面には`127.0.0.1:8989`を使います。複数のMCPクライアントと字幕アプリは、同じ共有サービスを利用します。

自動実況では、ゲームの状態・会話テキスト・最近の変化などをClaude Codeへ渡します。MCPの画面取得を使う場合は、画像とゲーム情報を接続先のクライアントへ渡します。

設定やアプリログは`runtime/`に保存します。画面取得用の一時PNGは、読み取り後に削除します。ROM・認証情報をリポジトリへ追加する必要はありません。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| BizHawkが未接続 | アプリまたはMCPサーバーを先に起動し、ソケット指定とLuaスクリプト付きでBizHawkを起動したか |
| Luaが動かない | BizHawkのLua Consoleで`lua/bridge.lua`が読み込まれているか |
| 再起動後に応答しない | BizHawkの接続とLuaスクリプトを再起動する。自動再接続は未対応 |
| 自動実況が出ない | 対応ROMか、読み取り可能なマップ場面か、見守りが開始済みか |
| 音声が出ない | ブラウザの音声設定と、操作画面で選択した音声を確認 |
| ポートが使用中 | 旧版や別のプロセスを終了する。全クライアント終了後、共有サービスの停止まで最大15秒待つ |

`BIZHAWK_PORT`でブリッジ側のポートを変更できます。その場合は、BizHawk起動時にも同じ値を`-Port`で指定してください。`COMMENTATOR_PORT`は`npm.cmd run app`で起動する操作画面のポートを変更します。ダブルクリック用ランチャーは既定ポートを使用します。

## 開発

```powershell
npm.cmd test
npm.cmd run check
```

テストはモックとLua VMを使い、通信・ゲーム情報の読み取り・実況選択・翻訳などを検証します。接続確認コマンドはローカルMCPサーバーを一時起動します。

# BizHawk Commentator

Local game commentary for BizHawk, with Japanese/English subtitles, browser speech synthesis, and optional Claude commentary through Claude Code. Also provides a read-only MCP server for screenshots and game context.

Automatic RAM-based commentary currently supports a specific Japanese version of Fire Emblem: Shadow Dragon and the Blade of Light. Windows, Node.js 22+, BizHawk, and a separately supplied game ROM are required.

See the [日本語 README](README.ja.md) for installation, usage, compatibility and limitations.
